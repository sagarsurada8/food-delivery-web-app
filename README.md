🍔 Food Delivery Web Application

A full-stack Food Delivery Web Application built using Java, Spring Boot, React.js, and MySQL. The application provides a seamless platform for users to browse food items, manage their cart, place orders, and track their order history.

🚀 Features
🔐 User Registration & Login
🍕 Browse and Search Food Items
🛒 Add, Update & Remove Cart Items
📦 Place and Manage Orders
📋 Order History
👨‍💼 Admin Food & Menu Management
🔄 RESTful API Integration
📱 Responsive React.js Interface
🗄️ MySQL Database Integration
